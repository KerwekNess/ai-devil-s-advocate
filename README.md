# AI Content Manager

Микро-SaaS для генерации контент-плана на основе одной темы.

## Проблема
Создатели контента тратят часы на придумывание идей, заголовков и хэштегов.

## Решение
Введите тему — получите готовый контент-план: 5 идей для постов, текст поста, 3 заголовка, хэштеги.

## Технологии
- Python (Flask)
- Gonka API (DeAI)
- Cursor (вайбкодинг)

## Как запустить
1. Установите зависимости `pip install -r requirements.txt`
2. Создайте `.env` на основе `.env.example`
3. Запустите `python app.py`
